# 📚 05. Vocabulary & Grammar (Aim: 7.5+)

Thư mục lưu trữ từ vựng học thuật theo chủ đề (Topic-based Collocations) và các cấu trúc ngữ pháp giúp tối ưu điểm **Lexical Resource (LR)** & **Grammatical Range and Accuracy (GRA)**.

## 📌 Cấu trúc nội dung
- **Collocations theo chủ đề lớn**: Education, Environment, Technology, Health, Economy, Crime, Media, Government.
- **Chủ điểm ngữ pháp ăn điểm Band 7.5+**:
  - Mệnh đề quan hệ rút gọn (Reduced Relative Clauses).
  - Câu điều kiện hỗn hợp & Đảo ngữ (Inversion).
  - Cụm danh từ hóa (Nominalization) giúp văn phong Writing học thuật hơn.
