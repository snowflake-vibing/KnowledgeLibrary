Bài 1: Tính toán Hệ số Tự tương quan mẫu bậc 1 ($r_1$)

Cho chuỗi thời gian gồm 5 quan sát: $y = [10, 14, 12, 18, 16]$ với $t = 1, 2, 3, 4, 5$.

Bước 1: Tính giá trị trung bình mẫu $\bar{y}$:

$$\bar{y} = \frac{10 + 14 + 12 + 18 + 16}{5} = \text{ [ } \text{ ] }$$

Bước 2: Tính mẫu số phương sai $\sum_{t=1}^{5} (y_t - \bar{y})^2$:

$(10-14)^2 + (14-14)^2 + (12-14)^2 + (18-14)^2 + (16-14)^2 = 16 + 0 + 4 + 16 + 4 =$ [ ]

Bước 3: Tính tử số hiệp phương sai với độ trễ $k=1$ (tổng $\sum_{t=2}^{5} (y_t - \bar{y})(y_{t-1} - \bar{y})$):

$(14-14)(10-14) + (12-14)(14-14) + (18-14)(12-14) + (16-14)(18-14) = 0 + 0 + (-8) + 8 =$ [ ]

Bước 4: Tính hệ số tự tương quan $r_1 = \frac{\text{Tử số}}{\text{Mẫu số}}$:

$r_1 =$ [ ] *(kết quả làm tròn 2 chữ số thập phân)*

Lời giải:

1. $\bar{y} = \frac{70}{5} = 14.0$.

2. Mẫu số $\sum (y_t - \bar{y})^2 = (-4)^2 + 0^2 + (-2)^2 + 4^2 + 2^2 = 16 + 0 + 4 + 16 + 4 = 40$.

3. Tử số với $k=1$: $(14-14)(10-14) + (12-14)(14-14) + (18-14)(12-14) + (16-14)(18-14) = 0 + 0 + (4 \times -2) + (2 \times 4) = -8 + 8 = 0$.

4. $r_1 = \frac{0}{40} = 0.00$. Chuỗi không có tương quan tuyến tính bậc 1.

Bài 2: Tính Trung bình trượt trung tâm (CMA) và Dự báo Mô hình Nhân

Cho dữ liệu bán hàng theo quý: $y_1 = 40$ (Q1), $y_2 = 56$ (Q2), $y_3 = 68$ (Q3), $y_4 = 92$ (Q4), $y_5 = 50$ (Q1 năm sau).

Bước 1: Tính Trung bình trượt trung tâm $\text{CMA}_3$ (quý 3):

$$\text{CMA}_3 = \frac{0.5 \times 40 + 56 + 68 + 92 + 0.5 \times 50}{4} = \text{ [ } \text{ ] }$$

Bước 2: Tính tỷ số mùa vụ thô tại Quý 3: $z_3 = \frac{y_3}{\text{CMA}_3}$:

$$z_3 = \frac{68}{\text{CMA}_3} = \text{ [ } \text{ ] } \text{ (lấy 3 số thập phân)}$$

Bước 3: Giả sử chỉ số mùa vụ chuẩn hóa của Quý 3 là $S_3 = 1.0392$. Tính giá trị doanh số đã khử mùa vụ $d_3 = \frac{y_3}{S_3}$:

$$d_3 = \frac{68}{1.0392} = \text{ [ } \text{ ] } \text{ (triệu VNĐ)}$$

Bước 4: Cho đường xu hướng $\hat{T}_t = 36.5 + 8.5 \times t$. Với Quý 1 năm 3 ($t=9$), chỉ số mùa vụ Quý 1 là $S_1 = 0.6950$.

Giá trị xu hướng tại $t=9$: $\hat{T}_9 = 36.5 + 8.5 \times 9 =$ [ ]

Dự báo doanh số điều chỉnh mùa vụ $\hat{y}_9 = \hat{T}_9 \times S_1 =$ [ ]

Lời giải:

1. $\text{CMA}_3 = \frac{20 + 56 + 68 + 92 + 25}{4} = \frac{261}{4} = 65.25$.

2. $z_3 = 68 / 65.25 \approx 1.0421$.

3. $d_3 = 68 / 1.0392 \approx 65.435$ triệu VNĐ.

4. $\hat{T}_9 = 36.5 + 8.5 \times 9 = 113.0$.

5. $\hat{y}_9 = 113.0 \times 0.6950 = 78.535$ triệu VNĐ.
