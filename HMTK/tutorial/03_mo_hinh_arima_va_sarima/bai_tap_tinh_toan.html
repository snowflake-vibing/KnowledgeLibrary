Bài Tập Tính Toán Điền Khuyết: Mô Hình Thống Kê ARIMA

Thực hành tính toán: Kỳ vọng dừng, Phương sai quá trình AR(1), Dự báo đệ quy mô hình ARMA(1, 1) và Phục hồi sai phân ARIMA(1, 1, 0).

Điểm số: 0 / 11 ô điền

Bài 1: Tính toán Kỳ Vọng và Phương Sai Quá Trình AR(1)

Cho quá trình tự hồi quy bậc 1 có phương trình: $y_t = 6.0 + 0.7 y_{t-1} + \epsilon_t$, với phương sai nhiễu trắng $\sigma_\epsilon^2 = 1.02$.

Bước 1: Tính kỳ vọng trung bình dài hạn $\mu = \frac{c}{1 - \phi_1}$:

$$\mu = \frac{6.0}{1 - 0.7} = \frac{6.0}{0.3} = \text{ [ } \text{ ] }$$

Bước 2: Tính phương sai của chuỗi $\text{Var}(y_t) = \frac{\sigma_\epsilon^2}{1 - \phi_1^2}$:

$$\text{Var}(y_t) = \frac{1.02}{1 - 0.7^2} = \frac{1.02}{1 - 0.49} = \frac{1.02}{0.51} = \text{ [ } \text{ ] }$$

Lời giải:

1. $\mu = 6.0 / (1 - 0.7) = 6.0 / 0.3 = 20.0$.

2. $\text{Var}(y_t) = 1.02 / (1 - 0.49) = 1.02 / 0.51 = 2.0$.

Bài 2: Tính Dự Báo Đa Bước Mô Hình ARMA(1, 1)

Cho mô hình: $y_t = 8.0 + 0.5 y_{t-1} + 0.3 \epsilon_{t-1} + \epsilon_t$.

Tại thời điểm $t = 50$, quan sát được $y_{50} = 22.0$ và phần dư $\epsilon_{50} = 2.0$.

Bước 1: Tính dự báo 1 bước tới $\hat{y}_{51|50}$:

$$\hat{y}_{51|50} = 8.0 + 0.5(22.0) + 0.3(2.0) + 0 = 8.0 + 11.0 + 0.6 = \text{ [ } \text{ ] }$$

Bước 2: Tính dự báo 2 bước tới $\hat{y}_{52|50}$ (chú ý: $\mathbb{E}[\epsilon_{51}] = 0$):

$$\hat{y}_{52|50} = 8.0 + 0.5(\hat{y}_{51|50}) + 0.3(0) = 8.0 + 0.5 \times 19.6 = \text{ [ } \text{ ] }$$

Bước 3: Tính dự báo 3 bước tới $\hat{y}_{53|50}$:

$$\hat{y}_{53|50} = 8.0 + 0.5(\hat{y}_{52|50}) = 8.0 + 0.5 \times 17.8 = \text{ [ } \text{ ] }$$

Bước 4: Khi $h \to \infty$, giá trị dự báo sẽ hội tụ về kỳ vọng trung bình $\mu = \frac{8.0}{1 - 0.5}$:

$$\mu = \text{ [ } \text{ ] }$$

Lời giải:

1. $\hat{y}_{51} = 8 + 0.5(22) + 0.3(2) = 8 + 11 + 0.6 = 19.6$.

2. $\hat{y}_{52} = 8 + 0.5(19.6) = 8 + 9.8 = 17.8$.

3. $\hat{y}_{53} = 8 + 0.5(17.8) = 8 + 8.9 = 16.9$.

4. $\mu = 8 / (1 - 0.5) = 16.0$.
