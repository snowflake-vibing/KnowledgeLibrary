Bài Tập Tính Toán Điền Khuyết: Lan Truyền Xuôi Trong Mạng LSTM

Thực hành tính toán trực tiếp: Cổng quên (Forget Gate), Cổng vào (Input Gate), Cập nhật Ô nhớ (Cell State) và Cổng ra (Output Gate).

Điểm số: 0 / 11 ô điền

Bài 1: Tính toán Cổng Quên ($f_t$) và Cổng Vào ($i_t$)

Cho một tế bào LSTM đơn biến với đầu vào hiện tại $x_t = 2.0$ và trạng thái ẩn trước $h_{t-1} = 1.0$.

Hàm kích hoạt Sigmoid: $\sigma(z) = \frac{1}{1 + e^{-z}}$. Chú ý: $\sigma(0.0) = 0.500$.

Cổng quên (Forget Gate): $W_f = 0.5, U_f = 0.2, b_f = -1.2$

Giá trị tuyến tính $z_f = W_f x_t + U_f h_{t-1} + b_f = 0.5(2.0) + 0.2(1.0) - 1.2 =$ [ ]

Độ mở cổng quên $f_t = \sigma(z_f) =$ [ ]

Cổng vào (Input Gate): $W_i = 0.6, U_i = -0.2, b_i = -1.0$

Giá trị tuyến tính $z_i = W_i x_t + U_i h_{t-1} + b_i = 0.6(2.0) - 0.2(1.0) - 1.0 =$ [ ]

Độ mở cổng vào $i_t = \sigma(z_i) =$ [ ]

Lời giải:

1. $z_f = 0.5(2) + 0.2(1) - 1.2 = 1.0 + 0.2 - 1.2 = 0.0 \implies f_t = \sigma(0) = 0.5$.

2. $z_i = 0.6(2) - 0.2(1) - 1.0 = 1.2 - 0.2 - 1.0 = 0.0 \implies i_t = \sigma(0) = 0.5$.

Bài 2: Tính toán Trạng Thái Ứng Viên ($\tilde{C}_t$) và Cập Nhật Ô Nhớ ($C_t$)

Giả sử qua tính toán:

  • Độ mở cổng quên: $f_t = 0.5$
  • Độ mở cổng vào: $i_t = 0.5$
  • Trạng thái ô nhớ bước trước: $C_{t-1} = 4.0$
  • Trạng thái ứng viên mới: $\tilde{C}_t = 0.800$

Bước 1: Tính lượng thông tin được giữ lại từ ô nhớ cũ: $f_t \times C_{t-1} = 0.5 \times 4.0 =$ [ ]

Bước 2: Tính lượng thông tin mới được nạp vào: $i_t \times \tilde{C}_t = 0.5 \times 0.800 =$ [ ]

Bước 3: Tính trạng thái ô nhớ mới: $C_t = f_t C_{t-1} + i_t \tilde{C}_t = 2.0 + 0.4 =$ [ ]

Lời giải:

1. Thông tin giữ lại = $0.5 \times 4.0 = 2.0$.

2. Thông tin nạp mới = $0.5 \times 0.8 = 0.4$.

3. $C_t = 2.0 + 0.4 = 2.400$.

Bài 3: Tính toán Cổng Ra ($o_t$) và Trạng Thái Ẩn ($h_t$)

Với các giá trị: $x_t = 2.0, h_{t-1} = 1.0, C_t = 2.4$.

Thông số cổng ra: $W_o = 0.3, U_o = 0.4, b_o = -1.0$.

Bước 1: Tính giá trị tuyến tính cổng ra $z_o = W_o x_t + U_o h_{t-1} + b_o = 0.3(2.0) + 0.4(1.0) - 1.0 =$ [ ]

Độ mở cổng ra: $o_t = \sigma(z_o) =$ [ ]

Bước 2: Cho giá trị $\tanh(C_t) = \tanh(2.4) = 0.9837$. Tính trạng thái ẩn đầu ra:

$$h_t = o_t \times \tanh(C_t) = 0.5 \times 0.9837 = \text{ [ } \text{ ] } \text{ (lấy 3 chữ số thập phân)}$$

Lời giải:

1. $z_o = 0.3(2) + 0.4(1) - 1.0 = 0.6 + 0.4 - 1.0 = 0.0 \implies o_t = \sigma(0) = 0.5$.

2. $h_t = 0.5 \times 0.9837 = 0.49185 \approx 0.492$.
