Bài Tập Tính Toán Điền Khuyết: Các Phương Pháp San Bằng Hàm Mũ

Thực hành tính toán đệ quy: San bằng hàm mũ đơn (SES), Holt tuyến tính (Level & Trend) và Holt-Winters theo mùa.

Điểm số: 0 / 12 ô điền

Bài 1: Tính toán San Bằng Hàm Mũ Đơn (SES)

Cho chuỗi quan sát: $y_1 = 20, y_2 = 24, y_3 = 22, y_4 = 28$. Thiết lập hệ số san bằng $\alpha = 0.4$, giá trị khởi tạo ban đầu $\hat{y}_{1|0} = 20.0$.

Bước 1: Sau khi quan sát $y_1 = 20$, tính dự báo cho $t=2$:

$$\hat{y}_{2|1} = 0.4 \times 20 + 0.6 \times 20.0 = \text{ [ } \text{ ] }$$

Bước 2: Tại $t=2$, quan sát thực tế $y_2 = 24$. Tính sai số $e_2$ và dự báo cho $t=3$:

Sai số $e_2 = y_2 - \hat{y}_{2|1} = 24 - 20 =$ [ ]

Dự báo $\hat{y}_{3|2} = 0.4 \times 24 + 0.6 \times 20.0 =$ [ ]

Bước 3: Tại $t=3$, quan sát $y_3 = 22$. Tính dự báo $\hat{y}_{4|3}$:

$$\hat{y}_{4|3} = 0.4 \times 22 + 0.6 \times 21.6 = 8.8 + 12.96 = \text{ [ } \text{ ] }$$

Bước 4: Tại $t=4$, quan sát $y_4 = 28$. Tính dự báo cho tương lai $\hat{y}_{5|4}$:

$$\hat{y}_{5|4} = 0.4 \times 28 + 0.6 \times 21.76 = 11.2 + 13.056 = \text{ [ } \text{ ] }$$

Lời giải:

1. $\hat{y}_{2|1} = 0.4(20) + 0.6(20) = 20.0$.

2. $e_2 = 24 - 20 = 4.0 \implies \hat{y}_{3|2} = 20.0 + 0.4 \times 4.0 = 21.6$.

3. $\hat{y}_{4|3} = 0.4(22) + 0.6(21.6) = 8.8 + 12.96 = 21.76$.

4. $\hat{y}_{5|4} = 0.4(28) + 0.6(21.76) = 11.2 + 13.056 = 24.256$.

Bài 2: Tính toán Phương pháp Holt Tuyến Tính (Level & Trend)

Khởi tạo tại $t=0$: $l_0 = 80$, $b_0 = 5$. Thiết lập hệ số $\alpha = 0.2, \beta = 0.1$.

Bước 1: Tại $t=1$, quan sát thực tế $y_1 = 90$:

Cập nhật Level: $l_1 = 0.2 \times 90 + 0.8 \times (80 + 5) = 18 + 68 =$ [ ]

Cập nhật Trend: $b_1 = 0.1 \times (86 - 80) + 0.9 \times 5 = 0.6 + 4.5 =$ [ ]

Dự báo $\hat{y}_{2|1} = l_1 + b_1 =$ [ ]

Bước 2: Tại $t=2$, quan sát thực tế $y_2 = 94$:

Cập nhật Level: $l_2 = 0.2 \times 94 + 0.8 \times (86.0 + 5.1) = 18.8 + 0.8 \times 91.1 = 18.8 + 72.88 =$ [ ]

Cập nhật Trend: $b_2 = 0.1 \times (91.68 - 86.0) + 0.9 \times 5.1 = 0.568 + 4.59 =$ [ ]

Bước 3: Dự báo tương lai từ mốc $t=2$:

Dự báo thời điểm $t=3$ ($h=1$): $\hat{y}_{3|2} = l_2 + 1 \times b_2 = 91.68 + 5.158 =$ [ ]

Dự báo thời điểm $t=4$ ($h=2$): $\hat{y}_{4|2} = l_2 + 2 \times b_2 = 91.68 + 2 \times 5.158 =$ [ ]

Lời giải:

1. $l_1 = 0.2(90) + 0.8(85) = 18 + 68 = 86.0$. $b_1 = 0.1(86-80) + 0.9(5) = 0.6 + 4.5 = 5.1$. $\hat{y}_{2|1} = 86 + 5.1 = 91.1$.

2. $l_2 = 0.2(94) + 0.8(91.1) = 18.8 + 72.88 = 91.68$. $b_2 = 0.1(91.68 - 86) + 0.9(5.1) = 0.568 + 4.59 = 5.158$.

3. $\hat{y}_{3|2} = 91.68 + 5.158 = 96.838$. $\hat{y}_{4|2} = 91.68 + 2(5.158) = 101.996$.

Bài 3: Tính Dự Báo Holt-Winters Mô Hình Nhân

Sau 12 tháng (kết thúc năm, chu kỳ $m=4$ quý), mô hình ước tính được:

  • Mức hiện tại $l_{12} = 200.0$ triệu VNĐ
  • Độ dốc xu hướng $b_{12} = 8.0$ triệu VNĐ/quý
  • Chỉ số mùa vụ 4 quý: $s_9 = 0.80$ (Q1), $s_{10} = 1.10$ (Q2), $s_{11} = 0.90$ (Q3), $s_{12} = 1.20$ (Q4)

Bước 1: Tính dự báo Quý 1 năm kế tiếp ($t=13, h=1$, chỉ số mùa vụ $s_9 = 0.80$):

$$\hat{y}_{13|12} = (l_{12} + 1 \times b_{12}) \times s_9 = (200 + 8) \times 0.80 = \text{ [ } \text{ ] } \text{ (triệu)}$$

Bước 2: Tính dự báo Quý 2 năm kế tiếp ($t=14, h=2$, chỉ số mùa vụ $s_{10} = 1.10$):

$$\hat{y}_{14|12} = (l_{12} + 2 \times b_{12}) \times s_{10} = (200 + 16) \times 1.10 = \text{ [ } \text{ ] } \text{ (triệu)}$$

Lời giải:

1. $\hat{y}_{13} = (200 + 8) \times 0.80 = 208 \times 0.80 = 166.4$ triệu VNĐ.

2. $\hat{y}_{14} = (200 + 16) \times 1.10 = 216 \times 1.10 = 237.6$ triệu VNĐ.
