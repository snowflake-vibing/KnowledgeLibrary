Bài 3: Tính Dự Báo Đệ Quy Đa Bước (Recursive Strategy)

Mô hình hồi quy đã học có phương trình: $\hat{y}_t = 5.0 + 0.7 L_1 + 0.2 L_2$.

Tại thời điểm $t=10$, dữ liệu thực tế có: $y_9 = 40.0, y_{10} = 45.0$.

Bước 1: Tính dự báo cho thời điểm $t=11$ ($L_1 = y_{10} = 45.0, L_2 = y_9 = 40.0$):

$$\hat{y}_{11} = 5.0 + 0.7(45.0) + 0.2(40.0) = 5.0 + 31.5 + 8.0 = \text{ [ } \text{ ] }$$

Bước 2: Tính dự báo đệ quy cho thời điểm $t=12$ ($L_1 = \hat{y}_{11} = 44.5, L_2 = y_{10} = 45.0$):

$$\hat{y}_{12} = 5.0 + 0.7(44.5) + 0.2(45.0) = 5.0 + 31.15 + 9.0 = \text{ [ } \text{ ] }$$

Lời giải:

1. $\hat{y}_{11} = 5 + 0.7(45) + 0.2(40) = 5 + 31.5 + 8.0 = 44.5$.

2. $\hat{y}_{12} = 5 + 0.7(44.5) + 0.2(45) = 5 + 31.15 + 9.0 = 45.15$.
